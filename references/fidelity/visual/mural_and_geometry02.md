## REF01_geometry_01.png critique

The lower-stair curve now runs in the correct broad direction. The broad stair also reads frontally, repairing the strongest previous orientation mismatch. These improvements do not yet make the registered image close.

1. Concrete wall: hero occupied roughly normalized x.30–.49, y.55–.72; current render x.28–.45,y.59–.92. Its projected height is nearly twice the reference and it extends much too close to the camera. Investigate which traced segment should form the overhead wall/open recess, then near-plane calibration. Reducing wall height alone would not fix its incorrect footprint depth and visible face direction.
2. Lower stair foot: hero around x.41,y.85; current aroundx.46,y1.02, partially outside frame. Lower run is too large/near/long in projection relative to upper spiral. The far bridge was used as the only plane in calibration; add actual gallery rail and stair endpoints as nearby constraints before declaring scale correct.
3. Broad stair: orientation improved. Current top~y.59, foot~y.71 versus reference top~.55, foot~.70. It looks a little narrow (current~.06frame vsphoto~.075), but this should be checked jointly with camera and top bridge location. No need to undo new orientation.
4. Upper stair shells are now extremely bright and visually lose thickness in spots. Do not let altered lighting/materials obscure geometry assessment between passes. Reference white is satin with gradual gray underside shading.
5. New ground fascia and columns start to establish correct structure, but unfinished facade and missing foreground railing still prevent meaningful global likeness. Next camera check should contain corrected gallery edge, not merely a floating camera over empty foreground.

All image coordinates are approximate visual landmarks, not computed segmentation or a camera solution.
